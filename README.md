## Запуск

Рекомендуется запускать через CMake в IDE (я делаю так), но можно и через
командную строку из корня проекта. Тогда, возможно, придётся дополнительно
определять пути к CMake и Ninja.

```bash
cmake -S . -B build -G Ninja
cmake --build build
./build/task1 # подставить номер задачи
```
Собрать все сразу через `./build.sh`.
